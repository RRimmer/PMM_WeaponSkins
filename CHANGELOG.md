# PMM_WeaponSkins — изменения

## 0.1.1
- Доступ к настройкам скина (`Features`): StatTrak, именной тег, наклейки, брелки, износ, паттерн - для всех,
  VIP (группы) или администраторов. Недоступная настройка видна серой с замком; скин сохраняется со значением
  по умолчанию.
- Число слотов наклеек по правилам (`StickerSlots`), например VIPBronze - 2, VIPGold - 5. Остальные слоты с замком.
- Карточки оружия: вместо цветных точек - иконки стороны (Т, спецназ, обе).
- "Надето" на скинах, ножах и перчатках показывает, за какую сторону надето (иконка Т / спецназ / обе).
- Сторона в настройке скина по умолчанию - та, за которую вы сейчас настраиваете (раньше M4A1-S, AUG и др.
  всегда ставились за спецназ). Если скин уже стоит за обе стороны - "Обе стороны". Скин, настроенный только
  за другую сторону, открывается с её параметрами.
- Цвет меню и свечение по краям (`Theme`): свой цвет для КТ и Т (по умолчанию голубой и золотой), свой цвет свечения
  и сила свечения (GlowSize 0-3). 32 цвета на выбор по названию или любой #rrggbb (берётся ближайший), список - в конфиге.
- Стандартный агент и стандартные перчатки - картинки из файлов игры (свои для Т и спецназа) вместо нарисованных.
- RepaintPickedUp / RepaintPickedUpDefault: исправлено - выданное оружие (например, через админку, упавшее на землю)
  не перекрашивалось при подборе, потому что считалось "своим".

## 0.1.0
- Первая версия: своё панорамное меню для WeaponSkins by Star по согласованному HTML-макету.
- Главная: агент, перчатки, нож, Zeus, музыка, медаль, 6 категорий оружия, смена стороны по клику на второго агента.
- Агенты с фильтром фракций, снаряжение и оружие с сортировкой (редкость / название), надетое всегда первое.
- Настройка скина: сторона, износ, паттерн, StatTrak, именной тег.
- Наклейки (до 5 на оружие, предел CS2): места слотов, размер и допустимая поверхность взяты из моделей CS2, превью сопоставлено
  с картинками инвентаря по эталонным 3D-рендерам (учтены наклон и перспектива), отдельно для скинов и оружия без скина.
  Редактор: место (X / Y в единицах игры, шаг 0,01, клик по оружию ставит наклейку туда), поворот, потёртость.
  Пятая наклейка - на пятом месте модели, а где его нет (AK-47, AWP, M4A4 и др.) - на месте первого слота.
  За край поверхности наклейку не сдвинуть. Размера нет: CS2 не меняет размер наклеек (атрибут scale игнорируется).
- Брелок: места крепления из моделей CS2 (KeychainMarkup), вешается только на оружие, стандартное место - как у Valve.
  X / Z - координаты модели, сторона считается по поверхности, плюс шаблон. Брелки с нулевыми координатами или
  в воздухе открываются на стандартном месте. У Dual Berettas доступно только стандартное место.
- Выбор наклеек: разделы (обычные наклейки по умолчанию, все, каждый турнир отдельно - новые сверху), сортировка
  (новые / старые / редкость / название А-Я, Я-А), фильтр по редкости, поиск по кнопке-лупе. Из раздела "Обычные"
  поиск идёт по всем наклейкам. Брелки: сортировка и поиск.
- Под картинкой оружия - выбранный слот с кнопками "Изменить положение" и "Убрать".
- Поворот на превью совпадает с игрой (положительный угол - против часовой стрелки).
- При долгом листании наклеек меню пересоздаёт свою сущность (лимит 1024 картинок-классов): старое меню
  остаётся на экране, пока новое не отрисуется.
- Панорама открывается только при "Menu_Style": 3 в конфиге WeaponSkins; при 1 или 2 открывается меню WeaponSkins.
- Настройки игроков (масштаб, сортировки) хранятся в MySQL (по умолчанию в базе WeaponSkins) - общие для нескольких
  серверов. Сортировка наклеек и брелков теперь запоминается.
- RepaintPickedUpDefault: перекрашивать только подобранное оружие без скина, чужие скины не трогать.
- RepaintPickedUp (по умолчанию выключено): подобранное оружие перекрашивается в скин того, кто подобрал.
  Нужен WeaponSkins с WeaponSkinsApi.ApplyToWeapon.
- Доступ к разделам только для VIP или администраторов (Access): закрытый раздел виден с замком и не открывается.
  VIP - из VIPCore 2.x или VIPCore by dexter, флаги и группы админов - из CounterStrikeSharp (CS2-SimpleAdmin).
- Конфиг: какие разделы видны (Sections) и какие оружия, ножи и перчатки скрыть внутри них (HiddenWeapons).
- Масштаб меню (100 / 90 / 80 / 75 / 70 / 60 %) для экранов 4:3, 5:4 и 16:10: в шапке меню или !wsscale, у каждого
  игрока свой, по умолчанию - Scale в конфиге. Меню рисуется под 16:9, а не растягивается по ширине экрана.
- Тексты меню вынесены в plugins/PMM_WeaponSkins/lang/ru.json, en.json, tr.json: их можно править, новый язык -
  новый файл lang/<код>.json и "Language": "<код>".
- Языки меню: русский, английский, турецкий (Language: ru / en / tr).
- Ввод текста: экранная клавиатура (RU/EN, цифровой блок) и/или чат (InputMode).
- Списки: прокрутка колесом или страницы (ListMode).
- Конфиг поставляется готовым файлом PMM_WeaponSkins.json с описанием каждого параметра.
- Нужен WeaponSkins by Star с WeaponSkinsApi (изменения переданы автору WeaponSkins).
